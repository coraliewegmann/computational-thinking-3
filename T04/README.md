# Kartenansicht

Interaktive Karte, die Orte aus `orte.json` als Kreise anzeigt.
Die Kreisfläche passt zur Einwohnerzahl. Gezeigt wird Europa.

## Starten

Mit **Live Server** in VS Code öffnen (wegen `fetch` reicht Doppelklicken nicht).

## Bedienung

- **Breite:** Karte breiter oder schmaler machen
- **Zoom:** auf Rom hineinzoomen, Rom bleibt dabei an seiner Stelle

## Anpassen

- `AUSSCHNITT` in `script.js`: welcher Teil der Welt gezeigt wird
- `ZOOMPUNKT` in `script.js`: um welchen Ort gezoomt wird
- `orte.json`: Orte hinzufügen oder ändern
